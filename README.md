# 📊 Reputation Dashboard — AI-Powered Sentiment Analysis Platform

Reputation Dashboard este o aplicație interactivă construită în **Streamlit**, destinată analizei reputației companiilor pe baza datelor din social media. Platforma combină modele clasice de Machine Learning, modele lexicon-based și modele Transformer moderne pentru a oferi o perspectivă completă asupra sentimentului public.

Acest Space rulează versiunea oficială a aplicației, optimizată pentru Hugging Face Spaces.

---

## 🚀 Funcționalități principale

### ✔ Analiză de sentiment multi‑model
- **Logistic Regression** (clasificator tradițional)
- **VADER** (lexicon-based)
- **Transformer (HuggingFace)** — model real, CPU‑optimized

### ✔ Dashboard interactiv
- KPI-uri dinamice
- Filtre pe companie, perioadă, volum de date
- Vizualizări: distribuții, trenduri, heatmap-uri

### ✔ AI Insights (Groq LLM)
- Explicații tehnice generate automat
- Răspunsuri scurte, academice
- Cache inteligent pentru reducerea costurilor

### ✔ Live Pipeline
- Preprocesare în timp real
- Tokenizare
- Scoruri de sentiment
- Timpul exact al postării (UTC)

### ✔ Proof of Source
- Afișarea sursei originale
- Link direct către postarea Reddit
